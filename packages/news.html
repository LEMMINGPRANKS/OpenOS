OpenOS 1.0.2 is out!

Shipped today over OpenOS's very own network stack -- no GitHub needed.

What's new in 1.0.2

  • Directories: cd, pwd, and folders in the Files app
  • OpenJS: a JavaScript interpreter built in the kernel -- run demo.js!
  • Double-click files on the desktop or in Files to open or run them
  • HTML support: pages render in the new Browser window
  • This News app, fetched live from the update server
