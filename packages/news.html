OpenOS 1.4.0 is out!

DUAL BOOT! OpenOS now shares the drive like a grown-up OS.

What's new in 1.4.0

  • A REAL MBR partition table -- OpenOS lives in its own partition (type 0x7F)
  • Boot menu: pick OpenOS or the other OS (3 second timeout, key 2 to chainload)
  • Everything moved inside the partition: stage2, A/B kernel slots, the store
  • A/B kernel updates still work end to end, with automatic rollback
  • Saved files still survive reboot -- now partition-relative too
