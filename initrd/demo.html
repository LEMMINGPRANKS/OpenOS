Welcome to the OpenOS web!

This page is rendered by OpenOS's very own HTML engine, written from scratch inside the kernel. No Chromium, no WebKit -- just us.

Things to try

  • Double-click demo.js on the desktop to run OpenJS
  • Open the Files app and explore the docs folder
  • Type getspgk list in the shell for packages

News and updates arrive over our own TCP stack in v1.0.2.

This is a real browser demo: click Browser on the taskbar and type an address like 10.0.2.2:8080/news, then press Enter -- the page is fetched over our own network stack.
